# Gymlocke (IRL Stats) changelog

Each build is shipped as `IRLStats-vX.Y.Z.zip`. The version also shows in
the in-game AddOns list, the Gymlocke window title and `/irl version`.
Unzip so the folder is named `IRLStats` (not `IRLStats-v0.3.1`), or WoW
won't load it.

## v0.3.1 (Sep 30, 2026)
- Fix: levels 1-9 (the starter spec) are enforced again under the
  Windwalker rulebook.
- Version number in the window title and `/irl version`; this changelog.

## v0.3.0 (Sep 30, 2026)
- Brewmaster rulebook with its own ladder: Endurance, Brace, Hang, Power,
  Mobility, Balance, measured against your Test Day baseline
  (+15% / +30% / +50%).
- Each spec has its own Test Day, gates and rank; the mile and reaction
  time are shared.
- Spec switcher in the window to view or log either spec's ladder.

## v0.2.0 (Sep 28, 2026)
- Rebuilt on the Gymlocke Rulebook for Windwalker: six calisthenics
  disciplines, Gates 0-5, discipline keys, ranks, monthly retests with a
  7-day retry, flying on Mile Silver, Test Day wizard with video check.
- Earlier builds: solo-friendly self-tests, `/irl verify` at any level.

## v0.1.0 (Sep 26, 2026)
- First build: Personal mode for Windwalker with milestone ladders,
  daily habit and streaks.
